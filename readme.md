## Introduction 
This is the repo where I create my personal website. Please visit https://liangl2020.github.io/ for more information. 

## Accessing Website Locally 
1. Download the repo to local. 
2. Open folder in Teminal (using `ls` and `cd` commands or sometimes simply right click might get you there). 
3. Use command line `python3 -m http.server 8000`.
4. Open `http://localhost:8000` in local browser. 

## Trouble Shooting 
1. If anything looks different locally than actual github.io, try hard refresh the tab to clear out old cache (`shift`+`command`+`R` for mac).
